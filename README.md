# Публичный конфиг внутренней рекламы

Этот каталог предназначен для отдельного публичного репозитория `unlying/crosspromo-config`.
Скопировать только `config-v1.json` и этот README. Приватный игровой репозиторий не публиковать.
Адрес после публикации: `https://raw.githubusercontent.com/unlying/crosspromo-config/main/config-v1.json`.

Редактирование: изменить название, HTTPS-иконку и канонический адрес выбранного магазина в `config-v1.json`, сохранить коммитом в main. Не добавлять токены, исходники игр или пользовательские данные. Схема версии 1: до 32 KiB, TTL от 60 до 86400 секунд, независимые записи googleplay/rustore/appstore. packageName/bundleId/appStoreId должны соответствовать ссылке.

Raw HTTPS выбран потому, что для одного JSON достаточно GitHub, редактирования файла и истории изменений. Не нужны сервер, база, Firebase SDK, секреты в приложении или GitHub Actions. Бесплатные публичные репозитории не дают SLA; сетевой сбой или лимит обслуживаются встроенным fallback. Не использовать GitHub API с токеном из приложения. Ответ с ошибкой/невалидный JSON не заменяет рабочий кеш. Отмена изменений — revert коммита; клиенты применят обновление при следующем запуске с учётом кеша хостинга.

GitHub: https://docs.github.com/en/repositories/working-with-files/using-files/viewing-and-understanding-files
Альтернативы проверены 2026-11-01: Render Static Sites (нужен отдельный аккаунт/деплой и учёт трафика), Firebase Remote Config (нужны проект/клиентская интеграция и лимиты fetch). Для текущего JSON это лишняя инфраструктура.
